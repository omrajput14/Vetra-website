# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Vetra takes the security and integrity of agricultural biosecurity systems and veterinary data seriously.

If you believe you have found a security vulnerability in Vetra, please report it to our security team rather than opening a public issue:

- **Email**: omrajputt369@gmail.com
- **Subject**: `[SECURITY VULNERABILITY] <Brief Description>`

### Please Include:
1. Type of issue (e.g. buffer overflow, SQL injection, unauthorized access, broken access control).
2. Step-by-step instructions to reproduce the vulnerability.
3. Proof-of-concept code or network payloads where applicable.
4. Impact assessment on herd data or biosecurity quarantine parameters.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 24 hours.
- A status update or patch timeline will be communicated within 72 hours.
- We request that you observe responsible disclosure principles until a fix has been deployed.
